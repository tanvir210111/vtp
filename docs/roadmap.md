# 🚀 Video-to-Prompt Roadmap

## Phase 1: MVP Core (Current)
- [x] Next.js 14 Web UI with drag-and-drop upload & parameter selection
- [x] FastAPI server with file processing pipeline
- [x] Keyframe extraction, thumbnail poster creation, and scene cut detection
- [x] Visual analyzer for camera movement, lighting, color palette, and kinetics
- [x] Multi-target prompt generation (Midjourney v6, Flux.1, SDXL, Sora, Runway Gen-3)
- [x] History grid and formatted TXT/JSON/Markdown downloads
- [x] Docker setup

## Phase 2: Enhanced Vision Models
- [ ] Integration with local Ollama / Qwen2-VL engine
- [ ] Automated video object tracking mask generation
- [ ] Audio sentiment & soundscape analysis integration

## Phase 3: Batch & Cloud Capabilities
- [ ] Multi-video batch processing queue
- [ ] Cloud storage provider connectors (AWS S3, Google Cloud Storage)
- [ ] Live webhook notifications on processing completion
